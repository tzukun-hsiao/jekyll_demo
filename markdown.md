# Markdown Examples

## Headings

```text
# Heading 1
## Heading 2
### Heading 3
```
# Heading 1
## Heading 2
### Heading 3

## Text Formatting

`*Italic text*`: *Italic text*

`**Bold text**`: **Bold text**

## Lists
### Unordered List

```text
- Item 1
- Item 2
- Item 3
```
- Item 1
- Item 2
- Item 3


### Ordered List

```text
1. First item
2. Second item
3. Third item
```

1. First item
2. Second item
3. Third item
