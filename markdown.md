# Markdown Examples

## Headings

To create headings, use one or more `#` symbols.

```text
# Heading 1
## Heading 2
### Heading 3
```
# Heading 1
## Heading 2
### Heading 3

## Text Formatting

*Italic text*

**Bold text**

***Bold and italic text***

Example:

Italic text

Bold text

Bold and italic text

Lists
Unordered List
- Item 1
- Item 2
- Item 3

Example:

Item 1
Item 2
Item 3
Ordered List
1. First item
2. Second item
3. Third item

Example:

First item
Second item
Third item
